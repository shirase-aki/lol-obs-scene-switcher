# LoL OBS Scene Switcher v0.1.0

League of Legends の**試合開始・終了を検知して、OBSのシーンを自動で切り替える**無料ツールです(Windows用)。

- 試合が始まる → 「試合中のシーン」へ
- 試合が終わる → 「試合外のシーン」へ
- 試合中に手動でシーンを変えても、勝手に戻しません(切り替えるのは開始時と終了時の1回ずつ)

インストーラーも exe もありません。**中身は読める PowerShell スクリプト(`.ps1`)と、それを起動する `.bat` だけ**です。ソースコードがそのまま配布物です。

## 導入手順

1. **OBSのWebSocketサーバーを有効にする**
   OBS の「ツール → WebSocketサーバー設定」→「WebSocketサーバーを有効にする」にチェック。
   「サーバーポート」と「サーバーパスワード」(認証を有効にした場合)を控えておきます。OBS 28 以降に標準搭載です。
2. **zip を解凍する**(「すべて展開」)。
3. **`Start-LolObsSceneSwitcher.bat` をダブルクリック**。
   タスクバーに最小化されたコンソールが出ますが、閉じないでください(閉じるとツールも終了します)。ウィンドウが開きます。
4. ポートとパスワードを入れて **「接続 / シーン一覧を更新」** を押す。
5. 「試合中のシーン」「試合外のシーン」をプルダウンで選ぶ。
6. LoL をプレイして、試合開始で切り替われば完了。設定は保存され、次回起動時に復元されます。

状態表示: `OBS: 接続済み / 未接続`、`LoL: 待機中 / 試合中`。
OBS を後から起動しても、ツールは自動で再接続します。

## このツールが何をするか(安全性について)

作者は個人です。見知らぬツールを動かすのは不安だと思うので、やることを全部書きます。コードは `LolObsSceneSwitcher.ps1` 1ファイルで、誰でも読めます。

### 監視するもの
- **`League of Legends.exe` というプロセスが存在するか**だけを、1秒ごとに Windows 標準の `Get-Process` で確認します。
- ロビー(`LeagueClient.exe`)は対象外です。試合の読み込み開始〜終了の間が「試合中」になります。
- 画面、ゲーム内データ、メモリ、キー入力、チャット、Riotアカウント情報は一切読みません。LoL のプロセスに介入(インジェクション等)もしません。

### 接続するもの
- **あなたが設定した OBS WebSocket サーバーだけ**(既定 `127.0.0.1:4455` = 同じPC内)に接続します。
- 送るのは、シーン一覧の取得(`GetSceneList`)と、シーン切替(`SetCurrentProgramScene`)だけです。
- **外部のサーバーには一切通信しません。** テレメトリ、アップデート確認、広告、アカウント機能はありません。(ホストに別PCのアドレスを入れた場合のみ、そのPCに接続します。)

### 保存するもの
| 内容 | 場所 |
|---|---|
| ホスト、ポート、シーン名、ON/OFF | `%APPDATA%\LolObsSceneSwitcher\settings.json` |
| OBS WebSocketのパスワード | 同じファイル内。**Windows DPAPIで暗号化**(同じWindowsユーザーでしか復号できない) |

- ログファイルは作りません。上記以外は何も保存しません。
- 配信画面にこのフォルダやファイルを映さないでください(暗号化されていても念のため)。
- アンインストール: ツールのフォルダと `%APPDATA%\LolObsSceneSwitcher\` を削除するだけです。レジストリ・サービス・スタートアップ登録はありません。

### 権限
- **管理者権限は不要**です。要求もしません。

## Windows Defender / SmartScreen について

- ダウンロードしたスクリプトに「Windowsによって PC が保護されました」や、ウイルス対策ソフトの警告が出ることがあります。理由は、**作者が無名の個人で、コード署名(有料の証明書)をしていない**ためです。署名のないファイルは、評判がないものとして一律に警告されます。悪意の判定ではありません。
- 起動用の `.bat` が `-ExecutionPolicy Bypass` を使うのは、このスクリプトを**この1回の起動に限って**実行可能にするためです。システム全体のセキュリティ設定は変えません。
- **セキュリティ機能を無効にする必要はありません。** 警告が気になる場合は、次のように確認してから使ってください。
  1. `LolObsSceneSwitcher.ps1` を自分で読む(または詳しい人に見せる)。
  2. 下の **SHA-256 ハッシュ**が Release ページの値と一致することを確認する。
  3. Release ページの VirusTotal の結果を見る。
- 確認して不安が残るなら、使わないのが正解です。

## ファイルの確認方法(SHA-256)

Release ページに zip の SHA-256 を載せます。手元で確認するには、PowerShell で次を実行します。

```powershell
Get-FileHash .\LolObsSceneSwitcher-v0.1.0.zip -Algorithm SHA256
```

zip の中の `SHA256SUMS.txt` には、各ファイルのハッシュが入っています。配布物は**ソースそのもの**なので、公開リポジトリの同じタグのファイルとハッシュが一致します。

## 制限事項(v0.1)

- LoL専用です(TFT等は未対応)。
- Windows 10 / 11 + 標準の Windows PowerShell 5.1 で動作します(追加インストール不要)。
- 起動中は最小化されたコンソールが残ります。
- 試合の開始 = `League of Legends.exe` の起動(読み込み画面)です。ゲーム内の時計は見ていません。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 「OBSに接続できません」 | OBS が起動しているか。WebSocketサーバーが有効か。ポート番号が合っているか |
| 「パスワードが違います」 | OBS の WebSocket 設定のパスワードと一致しているか |
| シーン名の選択肢が空 | 「接続 / シーン一覧を更新」を押す。OBS に接続できていれば一覧が出ます |
| 「切替失敗: No scene」 | OBS 側でシーン名を変更していないか。プルダウンから選び直す |
